## 2. 기술 통계

### 2-A. 부정 감정 (Negative Emotion, NEG)

$$\mu_{NEG} = 1.7909, \quad \sigma_{NEG} = 0.8498$$

4점 리커트 정규화:

$$x_{norm} = \frac{x - 1}{4 - 1} = \frac{x - 1}{3}$$

$$\mu_{NEG,norm} = \frac{1.7909 - 1}{3} = 0.2636, \quad \sigma_{NEG,norm} = \frac{0.8498}{3} = 0.2833$$

### 2-B. 자존감 (Self-Esteem, SE)

$$\mu_{SE} = 3.1430, \quad \sigma_{SE} = 0.7206$$

$$\mu_{SE,norm} = \frac{3.1430 - 1}{3} = 0.7143, \quad \sigma_{SE,norm} = \frac{0.7206}{3} = 0.2402$$

## 3. 카드 좌표계 → 부정 강도 점수

카드 공간: $x, y \in [-5, 5]$, 최대 유클리드 거리 $= \sqrt{5^2 + 5^2} = \sqrt{50} \approx 7.071$

부정 사분면 조건: $x < 0$ (빨강/파랑)

$$\text{card\_neg\_score}(x, y) = \begin{cases} \dfrac{\sqrt{x^2 + y^2}}{\sqrt{50}} & x < 0 \\ 0 & x \geq 0 \end{cases}$$

이 함수는 $[0, 1]$ 범위로 단조증가하며, 코너점 $(-5, \pm5)$에서 최댓값 1이 된다.

## 4. Z-점수 이상 탐지

주간 부정 점수 $S_{week}$ (카드 점수의 평균, 선택적으로 설문 점수와 평균):

$$Z_{NEG} = \frac{S_{week} - \mu_{NEG,norm}}{\sigma_{NEG,norm}}$$

자존감(보호 요인, 낮을수록 위험):

$$Z_{SE} = \frac{S_{SE} - \mu_{SE,norm}}{\sigma_{SE,norm}}$$

임계값:

| 단계 | NEG 조건 | SE 조건 |
|------|----------|---------|
| 주의 | $Z_{NEG} \geq 1$ | $Z_{SE} \leq -1$ |
| 위기 | $Z_{NEG} \geq 2$ | $Z_{SE} \leq -2$ |

원점수 임계값 (참고용):

| 지표 | 주의 (원점수) | 위기 (원점수) |
|------|-------------|-------------|
| NEG | 2.64 / 4.0 | 3.49 / 4.0 |
| SE  | 2.42 / 4.0 | 1.70 / 4.0 |

학년별 NEG 원점수 임계값:

| 학년 | 주의 | 위기 |
|------|------|------|
| 초4 | 2.37 | 3.14 |
| 초5 | 2.66 | 3.50 |
| 초6 | 2.84 | 3.72 |

## 5. 보조 플래그 (Auxiliary Flags)

세 개의 플래그는 Z-점수만으로 포착하기 어려운 패턴을 보완한다.

### FLAG 1 — HIGH_NEGATIVE_RATIO

$$R_{neg} = \frac{n_{neg}}{n_{total}} \geq 0.80$$

전체 카드의 80% 이상이 부정 사분면(x < 0)일 때 발동.

### FLAG 2 — HIGH_INTENSITY

$$\exists\, k \geq 2 : \sqrt{x_k^2 + y_k^2} \geq 5.0$$

거리 5 이상인 고강도 부정 카드가 2장 이상일 때 발동.

### FLAG 3 — PERSISTENT_NEGATIVE

$$\text{Var}(S_{daily}) < 0.50 \quad \text{AND} \quad S_{week} > 0.30$$

부정 감정이 변동 없이 지속될 때 발동. 감정 변화 없이 고착된 상태를 탐지.

$$\text{Var}(S) = \frac{1}{n}\sum_{i=1}^{n}(S_i - \bar{S})^2$$

## 6. 최종 분류 로직

```
if (Z_NEG ≥ 2) OR (Z_SE ≤ -2) OR (flag_count ≥ 2):
    status = "위기"
elif (Z_NEG ≥ 1) OR (Z_SE ≤ -1) OR (flag_count ≥ 1):
    status = "주의"
else:
    status = "정상"
```

카드 수 < 5 → `"분석중"` (분류 보류)

## 7. 정규화 통일성

모든 지표를 $[0, 1]$로 정규화하여 이질적인 척도(설문 리커트 vs. 카드 좌표 거리)를 동등하게 결합한다.

| 지표 | 정규화 공식 | 범위 |
|------|------------|------|
| 설문 리커트 (1–4) | $(x-1)/3$ | [0, 1] |
| 카드 부정 점수 | $d / \sqrt{50}$ | [0, 1] |
| 복합 점수 (설문 + 카드) | 단순 평균 | [0, 1] |

## 8. 알고리즘 한계

- **설문 데이터 연도 편차**: 2020–2022 NEG 평균 ≈ 3.3 (COVID 영향), 2024 ≈ 1.79. 임계값은 2024 기준으로 설정.
- **자존감 1문항 버전**: 다년도 분석은 Q30A4 단일 문항. 3문항 복합 점수는 2024만 해당.
- **카드 좌표 자기보고 편향**: 감정 선택은 학생의 주관적 인식에 의존.
- **최소 카드 수 제한**: 주 5회 기록 가정. 결석·미입력 시 분석 불가.
