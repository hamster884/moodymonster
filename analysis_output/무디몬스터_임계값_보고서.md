### 무디몬스터 앱 적용 기준값 (권장)

부정정서 3문항 평균 점수 기준 (1~4점 척도):

```
NEG_SCORE = (Q30A1 + Q30A2 + Q30A3) / 3

정상:  NEG_SCORE < 2.64
주의:  2.64 ≤ NEG_SCORE < 3.49   → 교사 알림
위기:  NEG_SCORE ≥ 3.49           → 즉시 개입 필요
```

> 참고: 학년이 높아질수록 부정 정서 점수가 높아지는 경향. 초6이 초4 대비 0.36점 높음. 학년별 임계값 적용 시 초4에게 더 민감하게 반응 가능.

## 6. 전처리 방법 요약

1. **초등 필터**: DDM2=1 (학교급=초등학교)
2. **학년 필터**: DM4(2020)/DM3(나머지) = 1,2,3 (초4·5·6)
3. **결측치**: 값=9 → NaN, 3문항 중 하나라도 NaN이면 행 제거
4. **역코딩**: Q30A6("자랑스러울게 없다") → 5-점수로 역코딩
5. **가중치**: wgt_b/WGT_B 적용, numpy.average(weights=) 사용
6. **2023 제외**: Q30 문항 구조 상이 (부정정서 측정 불가)
